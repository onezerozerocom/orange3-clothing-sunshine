# 날씨로 정하는 오늘의 옷차림

기상청 기상자료개방포털의 2025년 수원 날씨(강수량·기온·바람·습도·일조)를 오렌지3 **k-평균 군집 분석**으로 분석하는 학습지 웹앱입니다. 광고비-매출 v2와 같은 구성입니다.

`index.html` 파일 하나로 동작합니다. 크롬이나 엣지로 열거나, 깃허브 페이지 같은 곳에 올려 주소로 나눠 주면 됩니다.

## 학습지 구성

왼쪽 목록에서 STEP를 고르면 그 STEP 하나만 화면에 나옵니다. 맨 아래 **이전 · 다음** 버튼으로 넘어갈 수 있습니다. 모든 STEP에 **오렌지3에서 이렇게 해 보세요**(실습 안내)가 있습니다.

- **시작 · 문제 상황**: 생각 깨우기(군집 분석이란?), 재원이의 고민, 기온별 옷차림 표, 학습 흐름(단계 1~6과 STEP 연결)
- **STEP 0 · 데이터셋**: 속성 설명, `2025_수원_날씨.csv` 내려받기, 데이터 표
- **과제 1 · k-평균 군집 분석**
  - STEP 1 데이터 준비 · 속성 정하기 (열 선택 칸 고르기, 지도/비지도 학습)
  - STEP 2 분포 · 정규화 (데이터 분포, 열별 통계량)
  - STEP 3 k-평균 · 군집 수 정하기 (실루엣 점수), k-평균 시뮬레이터, 심화(군집 수 정하기 해설)
  - STEP 4 군집 결과 확인 (산점도로 군집 보기 → 데이터 분포로 날 수 → 박스플롯으로 평균기온·일조합 비교, 박스플롯 읽는 법, 날 수·평균·설명 표)
- **과제 2 · 군집 해석과 옷차림 추천**
  - STEP 5 군집 이름 · 옷차림 · 결과 정리 (데이터 테이블로 군집별 날짜 보기, 기온별 옷차림 표, 결과 정리 빈칸, 최종 위젯 배치 캡처)

군집 분석의 특성은 **평균기온·일조합** 두 개입니다. (열 선택: Features 평균기온·일조합, Metas 일시, 제외 강수량·평균풍속) STEP 2~5의 표와 시뮬레이터도 이 두 속성으로 되어 있습니다.

STEP 3에서 고른 군집 수 k에 맞춰 STEP 4~5의 군집 표(C1 ~ Ck)가 자동으로 만들어집니다. 캡처 칸은 STEP 4, 5에 있고, 과제 끝(STEP 4, STEP 5)에 과제별 PDF 저장 버튼이 있습니다.

## 학생은 이렇게 씁니다

1. 맨 위에 **학번·이름**을 적습니다.
2. STEP를 차례로 풉니다. 적은 내용은 **탭이 열려 있는 동안만** 저장됩니다. 새로고침해도 남아 있지만, 탭이나 브라우저를 닫으면 지워집니다.
3. 캡처 칸에 오렌지3 작업 화면을 붙여 넣습니다. (`Win` + `Shift` + `S` → 캡처 칸 클릭 → `Ctrl` + `V`, 또는 이미지 파일 끌어다 놓기)
4. **과제 1 / 과제 2 PDF로 저장** 버튼으로 제출용 PDF를 만듭니다.

입력칸에 맞지 않는 값을 넣으면 정답을 알려 주지 않고 형식만 점검해 줍니다. (예: 일시를 특성에 둠, 특성이 하나도 없음, 범위가 더 넓은 속성을 잘못 고름, 거리가 음수, 가장 가까운 쌍이 적은 거리와 맞지 않음, 실루엣 점수 범위, 날 수 합계가 365가 아님, 평균이 데이터 범위를 벗어남, 옷차림 단계가 평균기온과 많이 다름)

## 다시 만들기

- 분석 연도는 `merge_weather.py`와 `_build/build.py`의 `YEAR`(지금 2025)로 정해요. 다른 해로 바꾸려면 `데이터/`에 `YEAR_수원_요소.csv` 다섯 개를 넣고 두 파일의 `YEAR`를 바꾼 뒤 차례로 실행해요.
- `merge_weather.py`: `데이터/` 폴더의 기상청 원본 CSV(cp949)를 일시 기준으로 합쳐 `데이터/2025_수원_날씨_통합.csv`(전체 열)와 `2025_수원_날씨.csv`(일시 + 강수량·평균기온·평균풍속·일조합)를 만듭니다.
- `_build/`: 웹앱 원본(`template.html`)과 안내 그림. `python _build/build.py`를 실행하면 데이터와 그림을 넣어 `index.html`을 다시 만듭니다. 웹앱을 고칠 때는 `template.html`을 고친 뒤 다시 빌드합니다.
- 문제 상황의 옷차림 표 그림을 넣으려면 이 폴더에 `옷차림가이드.png`(또는 .jpg)를 두고 다시 빌드합니다. 그림이 없으면 같은 내용의 표가 대신 나옵니다.
